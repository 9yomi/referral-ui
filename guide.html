02

프로그레스 바 증가 액션

트리거: 친구 초대 완료 될 때마다

미리보기

친구한테 링크보내고 포인트 받기 0/10번

색상 — #61A5FF → #3183F7 고정 그라데이션. 색상은 변하지 않는다.

너비 증가 — Duration 650ms, Easing cubic-bezier(0.34, 1.56, 0.64, 1) (spring). 목표 너비를 살짝 넘었다가 돌아오는 탄성감이 있다.

번쩍 (Flash) — 없음. 빛 효과 미사용.

흰 도트 없음 — 바 끝에 원형 포인트는 사용하지 않는다.

⚠️ 구현 주의 — flash 애니메이션을 재실행하려면 클래스를 remove → reflow → add 순서로 처리해야 한다. 단순히 add만 하면 이미 재생 중일 때 반응하지 않는다.
🤖 구현 프롬프트 Guide 02
친구 초대가 완료될 때마다 프로그레스 바가 증가하는 애니메이션을 만들어줘. 3단계로 구성해: 1) 바가 넓어지면서 흰색 flash가 스쳐지나감 (300ms) 2) 바 끝에서 코인 아이콘이 바운스되며 등장 (spring easing, 400ms) 3) 숫자 카운터가 +1 증가 트리거는 친구 초대 완료 이벤트마다 반복 실행. 재실행 시 classList remove→reflow→add로 처리.

전체 시퀀스

1단계 — 회전 (0ms) : ↻ 아이콘만 0° → 360° 시계 방향 회전. duration 500ms, easing ease. 버튼 배경·크기는 변하지 않는다.

2단계 — fade out (520ms) : 아이콘 opacity 1 → 0 + scale 1 → 0.7. duration 200ms.

3단계 — ✓ 체크 등장 (720ms) : 아이콘 텍스트를 ✓ 로 교체 후 fade in. 색상 #4CAF50, scale 1.15로 살짝 크게. duration 200ms.

4단계 — 체크 유지 (720ms ~ 1420ms) : 700ms 동안 유지.

5단계 — fade out (1420ms) : 체크 아이콘 opacity 1 → 0. duration 220ms.

6단계 — ↻ 복귀 (1640ms) : 아이콘 텍스트를 ↻ 로 교체 후 fade in. 전체 시퀀스 종료.

대상 : 버튼 전체가 아닌 ↻ 아이콘 텍스트만 애니메이션 적용.

중복 클릭 : 시퀀스 진행 중 재클릭은 무시. 전체 시퀀스 완료 후에만 재실행 가능.

총 소요시간 : 약 1.6초.

⚠️ 구현 주의 — 회전 애니메이션 재실행 시 classList.remove → reflow(void el.offsetWidth) → classList.add 순서를 반드시 지킨다. reflow 없이 add만 하면 이미 재생 중일 때 반응하지 않는다.
🤖 구현 프롬프트 Guide 03
새로고침(↻) 버튼 클릭 시 아이콘이 360도 회전하는 애니메이션을 추가해줘. duration 600ms, easing cubic-bezier(0.4, 0, 0.2, 1). 클릭할 때마다 반복 실행 가능해야 해. 재실행 시 classList remove → reflow → add 순서로 처리해줘.

1단계 — 버튼 눌림 (0ms) : 버튼 scale 1 → 0.96, duration 120ms. 눌리는 물리감.

2단계 — 로딩 (120ms) : 버튼 텍스트 → 점 스피너로 교체. 처리 중임을 인지시킨다.

3단계 — 편지(보상받기 카드) 아래로 슬라이드 아웃 (530ms) : translateY(0 → 110%) + opacity 1 → 0, duration 380ms, easing cubic-bezier(0.4, 0, 1, 1). 카드가 아래로 사라진다.

4단계 — 결과 배경 fade in (650ms) : 고정된 그라데이션 배경 위로 결과 컨텐츠 레이어 opacity 0 → 1, duration 300ms. 상단 배너는 유지.

5단계 — sunburst 빛 등장 (750ms) : sunburst opacity 0 → 1, 이후 8s linear infinite 회전.

6단계 — 코인 spring 등장 (800ms) : translateY(30px) → 0 + scale 0.7 → 1.05 → 1, easing cubic-bezier(0.34, 1.56, 0.64, 1), duration 500ms.

7단계 — 텍스트 슬라이드 인 (1000ms) : translateY(-12px) → 0 + opacity 0 → 1, duration 350ms.

8단계 — 스파클 순차 등장 (1050ms~) : 각 스파클 50ms delay 간격으로 퍼진다.

9단계 — 2초 후 자동 dismiss : 버튼 없이 2000ms 후 자동 실행. 배경 + 컨텐츠 레이어 전체가 translateY(0 → -100%) + opacity 1 → 0 동시 적용. duration 500ms, easing cubic-bezier(0.4, 0, 0.2, 1). 상단 배너 뒤로 밀려 들어가는 효과.

💡 포인트 — 배경 그라데이션은 전환 내내 고정. 보상받기 카드 컨텐츠만 아래로 사라지고, 결과 컨텐츠(동전·텍스트·빛)만 위에서 애니메이션. dismiss 시에는 배경까지 통째로 위로 올라가 "이 구역이 사라진다"는 느낌을 준다.

플로팅 배너 원형 → 확장

친구 링크 클릭하면 100P 적립

애니메이션 시퀀스

1단계 — 원형 대기 (0ms) : width:36px 원형 상태로 노출. 코인 아이콘만 보임.

2단계 — 펼쳐짐 (자동, 1.5초 후) : width: 36px → 220px, duration 500ms, easing cubic-bezier(0.34, 1.2, 0.64, 1). 오른쪽으로 자연스럽게 확장.

3단계 — 텍스트 등장 (200ms delay) : opacity 0→1 + translateX(-6px→0), duration 250ms. 펼쳐진 후 텍스트 슬라이드 인.

4단계 — 노출 유지 (3초) : 사용자가 읽을 수 있도록 유지.

5단계 — 접힘 (3.5초 후) : 텍스트 먼저 fade out → width: 220px → 36px, duration 350ms, easing ease-in. 다시 원형으로.

6단계 — 반복 : 8초 간격으로 2~5단계 반복.

💡 포인트 — 아이콘은 항상 고정 위치. 텍스트가 오른쪽으로 펼쳐지는 방향. overflow:hidden + white-space:nowrap으로 텍스트가 자연스럽게 잘리며 등장. 원형일 때도 코인 아이콘이 보여 무엇인지 인지 가능.
🤖 구현 프롬프트 Guide 05
플로팅 배너가 원형 → 가로로 펼쳐지는 애니메이션을 만들어줘. ① 기본 상태 (원형) - width: 36px, height: 36px, border-radius: 20px - 코인 아이콘만 노출, overflow: hidden ② 펼쳐짐 (1.5초 후 자동) - width: 36px → 220px, duration 500ms - easing: cubic-bezier(0.34, 1.2, 0.64, 1) — 살짝 튀는 spring 느낌 - 텍스트 200ms delay 후 opacity 0→1 + translateX(-6px→0) ③ 접힘 (3.5초 후) - 텍스트 먼저 fade out (100ms) - width 220px → 36px, duration 350ms, easing ease-in ④ 반복 - 8초 간격으로 자동 반복 - 아이콘은 항상 왼쪽 고정, 텍스트가 오른쪽으로 펼쳐짐
